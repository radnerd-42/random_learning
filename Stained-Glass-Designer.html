User Guide & Instructions

🔍 View Controls (Zoom & Pan)

  • Cursor-Centered Zoom: Scroll your mouse wheel up or down to zoom in or out. The view zooms directly toward your mouse pointer position.
  • Panning the Canvas: Press and hold the Middle Mouse Wheel (or hold Spacebar + Left Click) and drag to move across the workspace.
  • Reset View: Click "🎯 Reset Zoom & Pan" in the sidebar to return to default scale (100%).

🛠️ Construction Type & Cut Gaps

  • Copper Foil (4px): Renders a thinner ~1/24" (1.06mm) stroke width designed for tighter glass fits and pattern shears when foiling. Access via ⚙️ Settings.
  • Lead Came (6px): Renders a 1/16" (1.59mm) stroke representing the standard heart of the lead came between glass pieces.

✏️ Drawing Tools

  • Line 📏: Click once for start point, click again to set end point. Shows live distance and angle readouts.
  • Free Draw ✏️: Click and hold the left mouse button, then drag to draw smooth freehand paths. Release to finish.
  • 3P Arc 📐: Click 3 times: Start Point → End Point → Control Curvature Point.
  • Circle ⚪: Click once for center point, drag and click again to set radius.
  • Single S-Curve 〰️: Click start point and end point to draw a single fluid, smooth S-curve line (ideal for organic glass borders).
  • Rectangle ▭: Click start corner, click opposite corner.
  • Trim ✂️: Click any segment bounded by intersections to cut it away cleanly while preserving curves and smooth strokes.
  • Eraser 🧹: Click any line or shape to erase the entire object. Hovering highlights target shapes in red.

🧲 Snapping Features

  • Grid Snap: Magnetically snaps cursor to background grid intersections.
  • Endpoints: Snaps precisely to start/end points of existing shapes.
  • Midpoints: Snaps directly to center points of straight line segments.
  • Center Snap: Snaps to center points of drawn circles.
  • Snap Perpendicular: When drawing a line, snaps to form an exact 90° angle with target lines.

📄 Paper & Project Setup

  • Settings Menu: Access Units Mode, Construction Type, and Paper Setup by clicking ⚙️ Settings in the top sidebar header.
  • Units Mode: Switch seamlessly between Inches (in) and Millimeters (mm).
  • Paper Setup: Standard paper sizes (US Letter, Legal, Tabloid, ISO A4, A3, A2) in Portrait or Landscape.
  • Grid Size: Adjust the slider to increase or decrease grid spacing dynamically.

💾 Saving & PDF Export

  • Save Project 💾: Downloads your current draft as a reusable project file (.gls). Saves selected construction type.
  • Load Project 📂: Upload any saved .gls project file to resume drafting.
  • Export PDF 📄: Generates a full 1:1 true-scale printable template with the active stroke width for cutting glass patterns directly.

⌨️ Keyboard Shortcuts

  • Ctrl + Z — Undo last action
  • Ctrl + Y — Redo action
  • Esc — Cancel active drawing line/point buffer (or close open popups)
  • Spacebar (Hold) + Drag — Pan across canvas
