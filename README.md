Time to learn Rust.

- guess_game - modified version of the game from Rust's documentation (https://doc.rust-lang.org/book/ch02-00-guessing-game-tutorial.html)
- smpcalc - simple terminal calculator providing +-*/%
- tempcon - simple temperature converter from F to C and C to F
- word_count - counts the words (separated by spaces) in a file, and prints the contents of the file as well
- Glass - a simple, html-based designer for simple stained glass patterns, with the ability to save, load and print/export to pdf. Note that the .gls files are just json formatted, but more fun to have glass files. Includes templates, and nginx configuration for sites-available/sites-enabled
